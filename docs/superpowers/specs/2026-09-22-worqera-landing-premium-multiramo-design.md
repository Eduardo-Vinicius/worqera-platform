# Worqera Landing — premium multi-ramo (2026-09-22)

## Em uma frase

Landing minimal/premium que vende o **loop operacional** (fila + código/QR + consulta) para **vários ramos** — não “software de tênis”.

## Posicionamento

- **Produto:** fila multi-setor + consulta pública
- **Pitch:** cliente para de ligar (código/QR/consulta); equipe para de perguntar (kanban)
- **Sem wa.me** no produto (comercial Worqera no footer ok)
- **Prova:** CdT / Paulista como clientes reais; calçados = prova, não limite

## Estrutura

1. Header (Produto / Ramos / Preço) — sem theme toggle
2. Hero full-bleed — marca + headline + CTA + visual produto
3. Loop — Recebe → Fila → Cliente consulta
4. Ramos — tipografia (calçados, lavanderia, assistência…)
5. Na prática — mock kanban + consulta
6. Quem já opera — strip quieto
7. Preço + FAQ curto + footer

## Visual

- Papel `#F6F4F0`, ink `#121212`, acento brand só em CTA
- Sem glow/gradient roxo
- Fontes: Instrument Sans + IBM Plex Sans

## Critérios

- Brand test no 1º viewport
- Multi-ramo se reconhece
- Zero grid de ícones / estrelas / browser chrome fake
